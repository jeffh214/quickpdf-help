Getting started

QuickPDF merges, splits, and compresses PDFs, and turns photos into a PDF. The work happens on this phone. There is no account and no sign-in.

Tap a tool on the home screen. The chip says Free · Upgrade until you buy Pro, then it says Pro. The theme button switches Dark, Light, or Match system.

The same guide is saved in the app. Open it from the ? on the home screen, or from Help & FAQ in the theme menu. It works with no connection.

Merge PDFs

Open Merge, then Add PDFs. You need at least two files. On the free version you can merge 2 PDFs. Pro has no file limit.

The list order is the page order in the finished file. Use the up and down buttons to move a PDF, or the remove button to drop one.

Tap Merge. The new file is named from the first PDF, so notes.pdf becomes notes_merged.pdf. The card shows the total pages and the size.

Split PDFs

Open Split and choose one PDF. Free can take up to 5 pages. Pro has no page cap.

Page range: type the pages you want. Pages start at 1. Example: 1-3, 5, 8-10. Then tap Create PDF. The file is named like report_pages.pdf.

Pick pages: tap the page numbers. One file per page is on by default, and the button says Extract pages. Several pages are saved as a zip of single-page PDFs, named like report_pages.zip. Turn the switch off to keep the pages you tapped in one PDF, in the order you tapped them.

A PDF with more than 150 pages asks you to use Page range instead of the page chips.

Compress

Open Compress and pick a level, then choose a PDF and tap Compress.

Low keeps more detail and usually saves less space. Medium is the balance, and it is selected when you open the screen. High makes the smallest file, and the pages look softer.

Compress redraws each page as a picture. Text in the new file cannot be selected or copied. A PDF that is already small can get bigger, and the screen says so when that happens. A long or photo-heavy file can take a while. You can cancel.

Free includes 1 compress. That copy adds a footer: Made with QuickPDF Free. Pro has no limit and no footer. The file is named like report_compressed.pdf, and you see the size before and after.

Images to PDF

Open Images to PDF. Pick a page size: A4 (210 × 297 mm), Letter (8.5 × 11 in), or Fit, where the page follows the photo.

Tap Add images and pick JPEG, PNG, or WebP photos. One photo is one page. Reorder the list to set the page order.

Free includes 5 images. A sixth photo asks you to upgrade, and only the first five are kept. Pro has no image limit. Tap Create PDF. The file is named QuickPDF_images.pdf.

Pro image tools

To JPG, Resize photos, and Remove location sit under Image tools. They are Pro only. You can open a card on the free version, but the button says Unlock Pro and does not write a file.

Your original photo is left alone. One photo comes back as one file. Several photos come back as a zip: QuickPDF_jpg.zip, QuickPDF_resized.zip, or QuickPDF_clean.zip.

To JPG turns HEIC and PNG into JPEG. Quality is 85, 90, or 95. 90 is the default. The photo stays upright, including HEIC. A transparent PNG is filled with white. The JPEG does not include the photo's location. A very large HEIC may be saved smaller so the phone does not run out of memory. holiday.heic becomes holiday.jpg. If this phone cannot decode HEIC, the app says so and does not write a file. HEIC needs Android 9 or later.

Resize photos scales the long side down to 1920, 1280, or 800. 1920 is selected when you open the screen. Enlarge smaller photos is off unless you turn it on, so a photo that is already smaller stays the same size. Copies are JPEG without location data, named like holiday_1920.jpg.

Remove location saves a copy without GPS and other sensitive photo data. JPEG and PNG keep their type, named like holiday_clean.jpg or scan_clean.png. A HEIC photo becomes a JPEG, named holiday_clean.jpg. The original stays as it is.

Where files are saved and how to share them

When a file is ready, it is still inside QuickPDF. It is not in Downloads until you save it.

Save to a folder asks you where to put it. Save to Downloads puts it in the Downloads folder. If that name is already there, the new file is saved as name (1).pdf, name (2).pdf, and so on. The message names the file that was actually saved.

Share opens the Android share sheet with the real filename, for a PDF, a JPEG, or a zip such as QuickPDF_jpg.zip. Start over clears the files you picked so you can begin again.

Purchases

Tap Free · Upgrade on the home screen, then Unlock Pro. Google Play handles the payment. QuickPDF does not see your card.

The purchase is a one-time unlock for this Google account. It does not renew and it is not a subscription.

Bought Pro already? Open QuickPDF Pro and tap Restore purchase. Use the same Google account that paid. A purchase that is still pending unlocks when Google Play completes it.

Privacy

QuickPDF is offline. PDFs and photos are read and written on this phone. Nothing is uploaded. There are no ads and no analytics.

The developer does not receive your files, your name, or your location. Photo tools that drop location write a new file on the phone. They do not send that data anywhere.

The only purchase check is with Google Play, for the product quickpdf_pro. The app does not ask for location, contacts, camera, or microphone access.

Troubleshooting
Password-protected PDFs

QuickPDF can't open a PDF that asks for a password. Remove the password in another app, then try again. The app will say this PDF is password-protected.

Large files and slow compress

Compress redraws every page, so a long PDF or one full of photos can take a while. Leave the screen open, or tap Cancel. High makes a smaller file and can look softer. A PDF that is already small may not shrink, and it can grow. The result card tells you when that happens.

Can't find the output

The finished file stays in QuickPDF until you save it. Tap Save to Downloads, or Save to a folder and pick a place. The message names the file that was written. If the name was taken, look for the same name with (1) or (2) added.

Purchase not restored

Open QuickPDF Pro and tap Restore purchase while signed into the Google account that bought it. The phone has to reach Google Play for that check. A pending purchase does not unlock until Play finishes it. Pro does not expire, because it is not a subscription.

Share filenames

Share should show the real name, such as notes_merged.pdf, holiday.jpg, or QuickPDF_jpg.zip. Zips are shared as zip files, not as pictures. On some phones an image preview still titles itself Sharing image. The file you send is still the named JPEG.
